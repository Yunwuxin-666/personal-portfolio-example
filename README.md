# Personal Portfolio Example

一个简洁、响应式的个人作品集示例页面，基于纯 HTML + CSS，无需构建工具。

## 在线预览

打开 `index.html` 即可在浏览器中查看；也可以直接访问：
https://yunwuxin-666.github.io/personal-portfolio-example/

## 目录结构

- `index.html` — 单页作品集，包含关于我、作品、技能、联系等区块
- `README.md` — 本说明文件

## 如何改成你自己的作品集

1. 把 `index.html` 里的「你的名字」替换成你的名字。
2. 修改头像字母（当前为 `W`）或把 `.avatar` 换成你的照片。
3. 在「精选作品」区块替换项目名称与描述，可加上仓库链接。
4. 在「技能栈」里改成你真正掌握的技能。
5. 把联系邮箱 `hello@example.com` 换成你的邮箱。
6. 提交并推送到 GitHub；如果仓库公开，可在 Settings → Pages 开启 GitHub Pages。

## 本地运行

直接用浏览器打开 `index.html`，或在目录下启动一个静态服务器：

```bash
python -m http.server 8000
```

然后访问 http://localhost:8000
