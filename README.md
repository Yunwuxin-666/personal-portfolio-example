# Contact Cybernetic

A responsive, motion-led contact hero reconstructed from the MotionSites "contact-cybernetic" reference. Built with React, Tailwind CSS and motion/react.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:5173/.

## Build

```bash
npm run build
```

## What is implemented

- Transparent three-zone navigation with an animated hamburger and full-screen mobile menu.
- Typewriter headline, two-line intro copy, and multi-select service pills with a confirmation state.
- Horizontal mouse scrubbing of the source cybernetic film on desktop; muted looping autoplay on mobile.
- Deterministic `prefers-reduced-motion` state with the film paused on a composed frame.
- Responsive layouts verified at 1440×900, 1024×768, 768×1024 and 390×844.
